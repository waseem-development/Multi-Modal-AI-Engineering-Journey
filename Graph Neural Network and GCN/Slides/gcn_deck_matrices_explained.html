The four matrices that turn a graph into numbers a GCN can use.

IntroThe Big Picture: Graphs as Tables of Numbers

Why this deck exists

A neural network can't read a drawing of dots and lines, but it can read a matrix. This deck shows four matrices that describe the same graph in different ways: adjacency, incidence, degree and Laplacian. The last one (L = D − A) is the one GCNs are built on.

WordMeaning
NodeA dot (A to F in the slides). N = number of nodes = 6.
EdgeA line between two nodes. M = number of edges (7 in the incidence slides).
Directed / undirectedArrows (A→B is not B→A) / plain lines that work both ways.
Weighted / unweightedEdges carry a number (12, 10…) / edges just exist or don't.
Self loopAn edge from a node to itself (B and F in the later slides).
Think of it like: A graph drawing is a city map. The matrices are the spreadsheets the city keeps about it: who connects to whom, which road is which, how busy each junction is.

1Adjacency Matrix: The Basics

A square table that says who is connected to whom

Make a square table with one row and one column per node. Cell (row u, column v) answers: is there an edge between u and v? For 6 nodes that means A = N × N = 6 × 6, or 36 cells.

  • Unweighted: each cell is T/F (or 1/0).
  • Weighted: each cell holds the edge's weight. This deck writes −1 when there is no edge.
How to read the diagram: the graph has weights A–B 12, A–C 10, B–D 8, C–E 15, C–F 1, D–F 7, E–F 12. Every following slide reuses this same graph.
Think of it like: an attendance grid with students down the side and across the top, ticked where two people are friends.
Watch out: using −1 for "no edge" is this deck's choice. Many libraries use 0, so check which one you are looking at before doing maths on the matrix.

2–3Weighted: Undirected vs Directed

Arrows make the table non-symmetric

Undirected (slide 2): A–B with weight 12 appears once, at row A, column B. Directed (slide 3): arrows matter, so the same graph gets two extra edges, B→A (34) and E→A (23). They show up as the new numbers in rows B and E.

Key idea: read a directed matrix as row = from, column = to. A[B][A] = 34 means "from B to A costs 34", while A[A][B] = 12 is the separate trip A→B.
Think of it like: undirected is a two-way street. Directed is a set of one-way streets, where going there and coming back can cost different amounts (12 out, 34 back).
Watch out: a truly undirected graph gives a symmetric matrix (A[u][v] = A[v][u]). The slide only fills in one half to avoid repeating each edge. The other half is a mirror copy.

4–5Unweighted: Directed vs Undirected

Same table, just T or F

Each cell is just T or F. Slide 4 (directed) has a T for A→B, A→C, B→A, B→D, C→E, C→F, D→F, E→A and E→F. Slide 5 (undirected) keeps one T per line.

T/F is the same as 1/0. As numbers, this is the matrix A that GCNs later multiply with node features.

How to read the diagram: the purple T's are the edges. Row F is all F in the directed case, because F has no outgoing arrows.
Think of it like: a "who follows whom" table. B following A doesn't mean A follows B, which is the directed case.

6Looking Up Routes (the Aij Table)

A side table on top of the weighted directed matrix

Slide 6 repeats the weighted directed matrix and adds a small table pairing an entry like AAF with a route. The routes shown: A→B direct, A→C direct, A→F as A-C-E-F, C→D as C-E-A-B-D, and B→C marked X.

How to read the diagram: the right-hand table is not the matrix itself. It answers "how do I get from the first letter to the second?" by following arrows.
Watch out: as I read the graph, two of these look off. A→C→F (cost 10 + 1) is shorter than A-C-E-F, and B→A→C is a valid route, so B to C is not truly impossible. If X means "no direct edge" it is right, since A[B][C] = −1. Check which meaning your instructor intended.

7–8Incidence Matrix (Nodes × Edges)

Rows are nodes, columns are edges

A cell says whether that node touches that edge. Size is N × M, here 6 × 7.

GraphRule
Undirected (slide 7)1 if the node is an end of the edge, else 0. Every column has exactly two 1s.
Directed (slide 8)−1 if the edge leaves the node, +1 if it enters, else 0.
How to read the diagram: take column e1 (the A–B edge). Slide 7 gives 1 at A and B. Slide 8 gives −1 at A and +1 at B, so e1 is A→B. Every directed column has one −1 and one +1.
Think of it like: instead of a friendship grid, this is a list of cables: each cable (column) is plugged into exactly two devices (rows).
Watch out: these slides draw the graph without the self loops, which appear from slide 9 onwards. A self loop would need its own column.

9Degree Matrix

A diagonal table counting each node's edges

Entry (v, v) is the degree of v: how many edge-ends touch it. Everything off the diagonal is 0. The slide says it is the same for directed and undirected graphs, since it counts every edge touching the node.

NodeDegreeWhy
A2B, C
B4A, D, plus a self loop worth 2
C3A, E, F
D2B, F
E2C, F
F5C, D, E, plus a self loop worth 2
Think of it like: a scoreboard of how many friends each person has, with nothing about who the friends are.
Watch out: a self loop adds 2 to the degree (it leaves and comes back). That is why B is 4, not 3.

10Laplacian Matrix: The Idea

Degrees minus neighbours

The graph Laplacian combines two earlier matrices:

L = D − A
  • D — degree matrix: how many edges each node has.
  • A — adjacency matrix: which nodes are neighbours.
  • L — diagonal: the node's degree. Off the diagonal: −1 where two nodes are connected.

The slide calls it a measure of smoothness: how quickly values change between adjacent nodes. Tiny example: give A the value 1 and every other node 0. The edges A–B and A–C each differ by 1, so the total squared difference is 1² + 1² = 2, which equals LAA = 2. If all nodes had the same value the total would be 0, the smoothest case.

Think of it like: each node is a thermometer. L tells you how much neighbouring temperatures disagree. A smooth graph has neighbours that read nearly the same.

11–12Laplacian: Worked Example

Subtract A from D, cell by cell

Slide 11 shows D and A side by side (with self loops on B and F). Slide 12 subtracts them: D − A = L.

  • Diagonal: degree minus the self-loop entry. B: 4 − 2 = 2. F: 5 − 2 = 3.
  • Off-diagonal: a neighbour pair becomes −1 (A and B: 0 − 1 = −1).
  • Self loops cancel out: the 2 in A is subtracted from the 4 in D, so B's loop leaves no trace in L.
How to read the diagram: the red 2's in the slide 11 adjacency matrix mark the self loops. They are 2 because the slide counts a self loop as two connections.
Check your work: every row of L adds up to 0. Row C: −1 + 3 − 1 − 1 = 0. If a row doesn't sum to 0, you made a subtraction slip.
Think of it like: D is how many hands each person has, A is who is actually holding whose hand. L records what is left over, row by row, and sums to zero because every held hand has a partner.

13The NetworkX Exercise

Draw the graph and print each matrix in Python

The last slide points to a Jupyter exercise. A minimal version for the weighted graph from slide 1:

import networkx as nx G = nx.Graph() G.add_weighted_edges_from([("A","B",12),("A","C",10),("B","D",8), ("C","E",15),("C","F",1),("D","F",7),("E","F",12)]) A = nx.to_numpy_array(G, weight=None) # adjacency (1/0) D = A.sum(axis=1) # degrees L = nx.laplacian_matrix(G).toarray() # L = D - A
Watch out: this graph has no self loops, so its degrees are A2 B2 C3 D2 E2 F3, not the 4 and 5 on slide 9. Add G.add_edge("B","B") and G.add_edge("F","F") to match the slide, and check how NetworkX counts a loop in the degree.

AllCheat Sheet

The four matrices on one page

MatrixSizeWhat it says
Adjacency AN × NWho connects to whom. T/F or weights. Row = from, column = to.
Incidence IN × MWhich node touches which edge. Directed: −1 out, +1 in.
Degree DN × NDiagonal, edges per node. A self loop counts 2.
Laplacian L = D − AN × NSmoothness measure. Rows sum to 0. Self loops cancel.
GCN connection: L = D − A is where the GCN's normalisation comes from. D tells each node how much to scale its neighbours' messages, and A tells it who the neighbours are.
